# RM Brain - Link Saver V1

Tu asistente de productividad con IA - Construido con React, TypeScript y Tailwind CSS.

## 🚀 Despliegue

### GitHub
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/rmtecnologiascontables-lab/linksaverV1.git
git push -u origin main
```

### Vercel
1. Ve a https://vercel.com
2. Importa el repositorio de GitHub
3. Configura:
   - Framework Preset: Vite
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Click Deploy

## 🔧 Variables de Entorno (Opcional)

Si quieres conectar con Google Sheets:
```env
VITE_GOOGLE_SHEET_ID=tu_sheet_id
```

## 📱 Funcionalidades

- 🧠 RR SEARCHER - Buscador rápido
- 📚 Library - Guarda recursos
- ✍️ Prompt Studio - Crea prompts con IA
- 🔧 Toolkit - Herramientas personalizadas
- 🎵 Converter - Convierte audio a texto
- ✅ To Do XL - Gestor de tareas

## 🛠️ Desarrollo

```bash
npm install
npm run dev
```
